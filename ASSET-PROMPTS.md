# Original asset prompts

Both assets used the built-in image_gen tool in generation mode, one request each. No PixelLab connection was used.

## dist/assets/world.png — 1536 × 1024

Use case: stylized-concept
Asset type: landscape pixel-art game world map, dominant background beneath interactive HTML stage nodes.
Primary request: Chessia, a children's chess adventure world. A lush emerald grassy floating island with a winding sandy path beginning in a broad bottom-left clearing and passing through forest and a small village. Mountains occupy the upper left; a lilac rune temple occupies the upper middle; a stone rook citadel occupies the upper right. A distant ominous purple castle stands on a separate island at the far upper right. Turquoise rivers flow across the land into a waterfall. Charming tiny chess banners accompany the landmarks.
Style/medium: beautifully detailed SNES RPG 16-bit pixel art, strongly crisp square pixels, meticulous pixel clusters and clean stepped edges.
Composition/framing: wide landscape 1536x1024 or wider, top-down slightly isometric world map. Show the whole island with all landmarks readable and a connected winding route with open spaces for HTML stage nodes. Land fills most of the frame.
Lighting/mood: warm sunlight, welcoming and adventurous, magical children's fantasy.
Color palette: lush emerald greens, sandy gold paths, turquoise water, lilac temple and distant purple castle.
Constraints: exactly one image; no text, no UI, no labels, no chess board, no watermark. This is a world map artwork, not a screenshot or UI mockup.

## dist/assets/heroes.png — 1536 × 1024, transparent PNG

Use case: stylized-concept
Asset type: transparent pixel-art sprite sheet for small chess RPG game board tokens.
Primary request: Exactly six isolated charming chess RPG hero characters in a strict uniform 3 columns by 2 rows arrangement. Canvas 1536x1024 landscape, with six equal 512x512 square cells, one character centered in each cell and substantial transparent padding on every side. Row 1 left: pawn, a tiny young warrior with wooden shield and short sword. Row 1 middle: knight riding a tiny pegasus. Row 1 right: hooded bishop wizard holding an orb staff. Row 2 left: rook, a walking stone golem fortress. Row 2 middle: queen, a golden winged warrior princess. Row 2 right: king, a tiny kindly king with an oversized crown.
Style/medium: cohesive charming 16-bit SNES pixel art, chunky crisp square pixel clusters, clean stepped edges, readable high-contrast silhouettes suitable for small game tokens, consistent front three-quarter view and consistent relative visual scale across all six heroes.
Composition: exactly six sprites total, no duplicates, do not overlap cell boundaries, each fully visible with generous padding. Transparent empty space separates all sprites.
Constraints: genuinely transparent background with alpha, no ground scenery, no words, no labels, no grid lines, no watermark, no shadows outside each cell. Output one 1536x1024 PNG sprite sheet.
